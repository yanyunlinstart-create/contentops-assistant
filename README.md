# 内容生产助手 · ContentOps Assistant

一个面向多账号内容运营的轻量工作流工具。

它把发布计划、文案管理、营销提醒、数据回访、日报生成和飞书同步整合到同一个本地工作台中，帮助运营者把零散的内容动作整理成可追踪、可复盘的执行流程。

## 项目简介

ContentOps Assistant 是一个本地网页工作台，配合本地 Node.js 后端连接飞书开放平台。它适合个人或小团队在多账号内容运营中管理发布节奏、沉淀文案、记录发布结果、生成日报，并把关键记录同步到飞书多维表格。

当前版本更准确的定位不是“自动内容生产系统”，而是“多账号内容运营辅助工作台”。它重点降低判断成本、记录成本和复盘成本。

## 这个工具解决什么问题

- 多账号每天该先发谁、谁需要补发、谁进入营销节奏不容易判断。
- 文案生成、文案库、发布记录和复盘数据分散，后续追踪成本高。
- 营销内容需要单独标记、提醒删除和保留记录。
- 发布后 0 数据、低表现内容需要回访和处理建议。
- 日报、飞书同步、重复记录治理容易变成重复手工劳动。

## 它不是什么

- 不自动发布内容。
- 不自动抓取平台数据。
- 不自动删除平台内容。
- 不自动清理飞书重复记录。
- 不是全流程自动化内容工厂。

它的核心作用是辅助判断、记录、提醒和复盘。真实发布、平台数据查看、删除动作和关键异常判断仍然需要人工完成。

## 核心功能

- 今日发布工作台：查看今日发布进度、待处理账号、营销提醒、日报和数据治理入口。
- 账号发布状态管理：支持标记已发、撤销发布、手动补记、普通内容和营销内容区分。
- 文案生成与文案库：生成文案、保存文案、筛选未发布/已发布/待删除内容，并支持发布后反馈反哺后续生成。
- 营销管理：根据规则或人工指定提醒营销账号，记录营销内容，追踪待删除和已删除状态。
- 发布后数据回访：支持 20 分钟、2 小时、24 小时、48 小时阶段提醒，辅助处理 0 数据或低表现内容。
- 发布数据录入与汇总：人工录入播放/阅读、互动、激励、档位等数据，用于复盘和日报。
- 日报生成：生成今日/昨日日报，可保存到飞书日报表。
- 飞书同步：同步账号、发布记录、文案库、营销记录和日报，支持待同步队列和失败重试。
- 数据治理：扫描飞书发布记录重复项，生成处理建议和清理清单，支持人工处理标记。

## 使用场景

- 发布前：确认今天要发布哪些账号，识别补发、连续发布和营销节奏。
- 发布中：生成和整理文案，从文案库选择内容，手动完成平台发布后回到工具标记状态。
- 发布后：录入关键数据，查看 20 分钟到 48 小时回访提醒，记录删除或继续观察结果。
- 收尾复盘：生成日报，保存到飞书，处理同步失败任务和重复记录治理清单。

## 本地运行方式

### 1. 环境要求

- Node.js 18 或更高版本。
- 浏览器可直接打开本地 `index.html`。
- 如需飞书同步，需要一个飞书开放平台应用和多维表格。

### 2. 安装依赖

当前项目没有第三方 npm 依赖，但建议执行一次安装，方便生成本地 npm 环境：

```bash
npm install
```

Windows PowerShell 如果拦截 `npm.ps1`，可以使用：

```powershell
npm.cmd install
```

### 3. 配置环境变量

复制 `.env.example` 为 `.env`：

```powershell
Copy-Item .env.example .env
```

填写本地飞书应用配置：

```env
PORT=3000
FEISHU_APP_ID=cli_xxxxxxxxxxxxx
FEISHU_APP_SECRET=replace_with_your_feishu_app_secret
FEISHU_REPORT_CHAT_ID=
```

不要把 `.env` 提交到 GitHub。

### 4. 启动本地后端

```powershell
npm.cmd start
```

或直接运行：

```bash
node server.js
```

默认后端地址：

```text
http://localhost:3000
```

健康检查：

```text
http://127.0.0.1:3000/api/feishu/health
```

### 5. 打开前端

用浏览器打开：

```text
index.html
```

在页面设置中确认后端地址为 `http://localhost:3000`，并填写飞书多维表格配置。

## 飞书配置说明

飞书 App ID 和 App Secret 放在本地 `.env` 中；多维表格的 `app_token` 和各表 `table_id` 在网页设置中填写。

当前同步能力涉及以下表：

- 账号表
- 发布记录表
- 文案库表
- 营销记录表
- 日报表

飞书应用需要拥有对应多维表格的读写权限。真实密钥、表格 ID、业务数据和浏览器本地存储导出都不应提交到公开仓库。

## 当前版本能力边界

- 平台真实发布仍需人工完成。
- 平台数据查看和录入仍需人工完成。
- 营销内容或低表现内容的删除动作仍需人工确认。
- 飞书重复记录治理目前是人工辅助，不会自动删除、合并或更新飞书记录。
- 飞书同步失败时会进入待同步队列，但仍需要人工检查配置、权限或网络问题。
- 文案生成能力依赖用户自行配置的生成接口和提示词参数。

## 安全说明

本仓库不应包含真实账号名、设备号、API Key、飞书 token、飞书 app_secret、webhook、真实飞书表格 ID、真实发布记录、真实文案库、真实日报或真实营销内容。

请勿提交 `.env`、日志文件、本地备份、数据导出文件、浏览器 localStorage 导出或任何包含真实业务数据的文件。
