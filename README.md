# 内容生产助手 · 飞书同步版

## 项目简介

内容生产助手 · 飞书同步版是一个面向多账号内容运营场景的本地内容生产与飞书同步工具。它以本地网页作为主要工作台，配合本地 Node.js 后端连接飞书开放平台，用于把账号、发布记录、文案、营销记录和日报等运营信息同步到飞书多维表格。

## 项目定位

这个项目不是单纯 demo，而是一个实际工作流工具。它面向日常内容运营中的多账号管理、文案沉淀、发布留痕、营销记录、日报汇总、提醒处理和数据治理等工作，目标是减少重复整理和手工补记，让日常执行流程更稳定。

## 当前版本

v1.0.0 - 飞书同步版

## 核心功能

- 多账号内容发布管理
- 本地账号库同步到飞书账号表
- 发布记录同步，支持 upsert
- 文案库同步
- 营销记录同步
- 营销删除状态更新
- 待同步队列和失败重试
- 发布记录数据治理
- 日报 / 今日汇报生成
- 昨日未生成日报提醒
- 一键补生成昨日日报
- 日报保存到飞书日报表
- 飞书工作流通知
- 营销规则配置入口
- 指定营销账号 / 指定营销内容人工标记
- 网页提醒面板
- 今日工作台瘦身与界面优化

## 项目价值

在多账号内容运营中，常见问题包括漏发、漏记、重复整理、数据分散、日报手工汇总和异常难追踪。这个工具把内容生产、发布状态、文案归档、营销留痕、日报生成和飞书同步放到同一个工作流中，帮助运营者更清楚地知道今天该做什么、哪些已经完成、哪些需要补同步或复盘。

## 运行方式

### 1. 安装依赖

当前项目不依赖第三方 npm 包，但仍建议在项目目录中执行一次安装命令，方便后续扩展：

```bash
npm install
```

### 2. 配置环境变量

复制示例配置文件：

```bash
cp .env.example .env
```

Windows PowerShell 可使用：

```powershell
Copy-Item .env.example .env
```

然后在 `.env` 中填写你自己的飞书应用配置。不要把 `.env` 提交到 GitHub。

### 3. 启动本地后端

```bash
npm start
```

如果 PowerShell 执行策略阻止 `npm.ps1`，可以使用：

```powershell
npm.cmd start
```

或直接启动：

```bash
node server.js
```

默认后端地址为：

```text
http://localhost:3000
```

### 4. 打开网页

用浏览器打开：

```text
内容生产助手-GitHub发布版.html
```

在网页中的飞书配置区域填写多维表格相关配置，并测试连接。

## 环境变量说明

`.env.example` 仅提供字段模板，不包含任何真实配置。

```env
PORT=
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_REPORT_CHAT_ID=
```

字段说明：

- `PORT`：本地 Node.js 后端监听端口，默认可使用 `3000`
- `FEISHU_APP_ID`：飞书开放平台应用 ID
- `FEISHU_APP_SECRET`：飞书开放平台应用密钥
- `FEISHU_REPORT_CHAT_ID`：可选，用于日报或通知发送目标

飞书多维表格的 `app_token` 和各表 `table_id` 由网页端配置，请使用自己的真实配置，不要提交到仓库。

## 隐私与安全说明

本仓库不包含：

- 真实账号名
- 真实设备号
- API Key
- 飞书 token
- webhook
- 真实发布记录
- 真实日报内容
- 真实营销内容
- 真实飞书多维表格配置

真实配置请放在本地 `.env` 中。本仓库只提供 `.env.example` 作为字段模板。

请不要提交：

- `.env`
- 日志文件
- 本地备份
- 数据导出文件
- 浏览器 localStorage 导出
- 任何包含真实业务数据的文件
